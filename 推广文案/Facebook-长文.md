## 正文

```
【我为 DeepSeek Harness 写了一个 Windows 更新器】🐟🍚

从 0.5.0 写到 0.7.7，中间踩了不少坑，也修了不少。整理一下这段路。

────────────────────

▍这工具是干什么的

它帮你管理本机上的 DeepSeek Harness（DSH）：

· 自动检测装在哪 —— 源码检出 / npm 全局 / 运行时 profile 三类都能认
· 对比官方版本 —— 源码比 GitHub master，npm 比 npm registry
· 一键更新 —— 下载官方源码 zip → 自动备份 → 整目录替换
· 扫描插件与技能，显示名称、版本、大小、安装时间
· 提供 EXE 版与源码版两种形态

────────────────────

▍0.5.0 → 0.6.x：打地基

最早只是个能检测安装位置、比对版本号的小工具。
后来陆续加上安装时间显示、官方最新版检测，以及浅色 / 深色两套主题。

这个阶段的目标很简单：先把「看得见」做对。

────────────────────

▍0.7.0：多语言

一次上齐 5 种语言：

简体中文 · 繁體中文 · English · 日本語 · 한국어

跟随系统语言自动选择，也能手动切换。

最难的不是翻译本身，而是让「运行时拼出来的长句子」也能跟着切 ——
有一批消息在源码里是分成好几段写的（f"..." f"..."），
运行时是一条完整的，提取翻译键时却会被拆散。这块前后返工了两轮。

────────────────────

▍0.7.1 → 0.7.2：把粗糙处磨平

· 切换语言不再触发重新扫描
· 上次检测时间挪到右上角，启动时先读缓存立即显示
· 三类本地信息合并成一个 preferences.json（类似游戏的「玩家偏好档」）
· 更新源码后可选择自动执行 pnpm install / pnpm run build
· 翻译覆盖做到 100%，并加了测试守住

────────────────────

▍0.7.5：一次大更新

· 更新前若 DSH 还开着，弹窗列出进程、确认后自动关闭
  （此前开着更新会直接失败，npm 那条路还可能弄坏安装）
· 三路回滚：源码检出 / npm 全局 / profile，可单独回滚，也可一起
· 插件与技能合并进同一个窗口，用分页切换
· 列表列宽按字体实测重定，不再出现文字被截断

────────────────────

▍0.7.6 → 0.7.7：深色模式

· 修掉语言下拉框在深色下变成「空白白框」
· 回滚窗口整体改成纯黑，与主窗口区分开
· 深色模式现在会被记住，不用每次开程序都手动切一次

顺带说一个挺有意思的坑：界面里有个样式被使用却从未定义，
ttk 拿到未配置的样式名不会回退，而是直接渲染成一块黑色背景。
找了一阵子才定位到。

────────────────────

▍关于质量

目前 131 项测试全绿，GitHub Actions 每次推送都会跑。
Release 同时提供 EXE 版与源码版，并附 SHA256 校验值。

────────────────────

▍仓库地址

https://github.com/mutoharohfiqhiabcd-source/dsh-updater

欢迎试用、提 issue，也欢迎直接读代码。

此推由某个爱吃白饭的大肥鱼写之 🐟🍚

#DeepSeekHarness #DSH #開源專案 #开源项目 #GitHub #Python
```
