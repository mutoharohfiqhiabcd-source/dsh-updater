# Twitter / X 发布文案（线程）

> 说明：X 对中文按「2 字符」计数，所以每条都控制在 **140 个汉字以内**，可直接粘贴。
> 发布时按 1/7、2/7 … 依次发出，或直接用「发帖 → 添加」串成线程。

---

## 建议标签

主标签（每条都带 2–3 个即可，不要堆砌）：

```
#DeepSeekHarness #DSH #开源项目 #GitHub
```

备用（轮换使用，避免每条完全重复）：

```
#Python #Tkinter #Windows工具 #开源 #自建工具 #DeepSeek
```

## 建议栏目 / 话题

- X 无「栏目」概念，可用 **Communities（社区）** 投放：开源项目、Python、AI 工具类社区
- 或发在个人主页并置顶（Pinned），便于新访客第一眼看到
